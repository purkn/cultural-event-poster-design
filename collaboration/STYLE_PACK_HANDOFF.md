# Style Pack 团队交接清单 v0.13

提交新风格时必须包含：
- 参考图聚类说明
- substyles 是否必要
- >=4 张 core anchors
- router_profile
- retrieval_signature / asset_affinity
- operator_affinity
- hero_grammar
- **h0_strategy**
- artword_grammar（仅在该风格确实使用自定义艺术字时）
- medium/surface fingerprint
- typography_map
- layout_affinity
- negative_rules
- evaluator
- prompt_compiler
- >=4 个 regression briefs
- >=2 个 failure cases

验收重点：
1. 适合的 brief 上明显有优势；
2. 能识别自己不适合的 brief；
3. 输出不只是关键词表面相似；
4. H0 Strategy 与参考 Type DNA 一致；
5. medium/surface 不因主题自动漂移；
6. anchor-relative 输出能被 evidence-based critic 诚实评分。
