# Reference Blueprint Contract v0.13

## 目标
确保“参考”进入生成约束，而不是被主题语义和 Support Reference 改写。

## 1. Blueprint 三层
### STRUCTURE
- topology
- H0 / hero ratios
- type-image relation
- negative-space map
- information architecture

### SURFACE
- medium_class
- dimensionality
- background_value_regime
- color role count
- lighting_model
- surface_finish
- mark_frequency

### TYPE DNA
- H0 skeleton / contrast / weight / width / proportion
- arrangement
- fill_behavior
- effect_class
- supporting typography system

## 2. BORROW
明确要继承哪些：
- structure
- surface
- type DNA

## 3. TRANSFORM
只负责：
- subject/content
- event metaphor
- title literal text
- asset-specific transformation
- required information

## 4. DO NOT COPY
不得复刻原参考的具体独有角色、插画、文案、Logo、逐笔字形、精确像素位置。

## 5. Target Tolerance
Strong Lead：
- H0 area ratio ±20%
- hero area ±20%
- visual center shift <=0.10 canvas
- info density ±20%
- chromatic role count: same or ±1
- background value regime: same class
- medium_class: same family
- H0 weight: same or adjacent class
- H0 fill/effect class: same unless Concept strongly requires and PARTIAL_BREAK predeclared

## 6. PARTIAL_BREAK
若生成前预计突破 2 个以上全局维度，应重新检索 Lead，而不是默认 PARTIAL_BREAK。
只有确实没有更合适 Lead 时才允许使用。
