# Core Architecture v0.18 (running execution)

`Brief → Asset Audit → Visual Opportunity → Reference Retrieval → Fine Deconstruction → Lead Validity → Lead Dominance → Blueprint (Structure + Surface + Type DNA) → Typography Strategy → Concept → Rough Competition → Triple Delta → SVG-first Editable Composition (HTML preview optional) → Design/Production QA`

核心边界：
- Reference 决定视觉世界；
- Concept 决定主题转译；
- Asset Transformation 决定素材如何进入这个世界；
- Typography Strategy 决定 H0 是精确排印、艺术字还是字图融合；
- SVG + JSON Poster Plan 负责事实文字与最终可编辑排版；HTML/CSS 仅作共享数据源的可选预览。
