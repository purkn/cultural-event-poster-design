# H0 逐字变奏安全门槛

## 默认值
`h0.mode = STANDARD_BLOCK`。中文 H0 默认整行/整组字形一致，不允许 `per_glyph` 属性；换行允许，但每行保持基线、字号、字距协调。

## 只有以下全部成立才能启用 CUSTOM_GLYPH
- 当次 Lead 真有强烈的逐字形态差异，记录裁切图并描述每字变化的**具体证据**（而不是“年轻、活泼”）。
- 变化服务于概念：例如字与图互锁、具体笔画变形；不是随机 ±6° 或字号 204/176/138/126。
- 使用实际验证的字形轮廓路径（SVG path），**禁止靠 CSS transform 伪造**。
- 逐字准确且完整保留源文本；生成 SVG 后独立渲染截图核对。
- 在至少两个候选样张中选出设计上更好的一个，而非选最夸张的。

## 必须直接否决的快捷路径
- 无参考证据时，为五个汉字分别设置不同 font-size/rotation/scale。
- 把 H0 制作为一组不等比例的系统字体字符，宣称是“定制艺术字”。
- 仅因为文字排不下，将某些字独立缩小/放大，而不调整整个标题框或换行方案。
