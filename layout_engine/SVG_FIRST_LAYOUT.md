# SVG 海报排版架构

## 定位
本模块负责 SVG 与 JSON 母版的最终组装；不替换活动内容检查、Hero、参考检索、字体授权、双语翻译与审美评审。

**输出的权威设计源文件是 `poster_zh.svg` / `poster_en.svg` + 对应 `poster_plan.json`，PNG 只是导出预览。** 原图/摄影/生图 Hero 可在 SVG 内保留嵌入的位图，其它图层可用 SVG 文字、路径、形状编辑；这叫“可编辑的混合 SVG”，不是所有像素都矢量化。

## 推荐分工
- Hero：AI 生图或处理现有用户素材，导出图像。
- H0：`STANDARD_BLOCK` 默认整词/整行排印；`CUSTOM_GLYPH` 只有提供经过审校的真实字形路径才能启用。
- H1–H6：一律真实 UTF-8 SVG `<text>` 标签，明确字体文件、字体族和字号，不允许散成单字节点。
- 版式：统一的 frame / text / image / group 对象坐标系，画布坐标就是最终 SVG 的 viewBox；在 Figma/Illustrator/Inkscape 里可按图层移动。
- HTML：可用于大量信息输入、动态表单、排版预览或截图，但不再是唯一最终成图母版；若启用 HTML，必须从**同一 JSON Poster Plan**派生，禁止维护第二套独立坐标。

## 非常重要的“可编辑”边界
- SVG `<text>` 在 SVG 源文件中仍是实际文字；但 Figma 不同导入方式/版本可能把文字变为轮廓、拆为矢量节点，**不能保证导入后仍可直接改文字内容**。
- SVG `<path>`（艺术字轮廓）可以继续编辑贝塞尔曲线，但不等于可像普通文本框一样输入汉字。
- 要求 Figma 中内容原生可编辑时，建议以后另做 Figma 插件/API 导入器；本模块暂时以 **SVG 源码可改文本 + SVG 对象可改位置、颜色、形状** 为交付标准。
- 提供 `poster_plan.json` 保留每个文本字符串，可以重跑生成器，不因转曲而丢失源文案。

## 强制步骤
1. 字体真实文件与地区字形验证；参考 H0 样张 2 版比较，选择非缓存默认字体。
2. H0 先在版式中以整体设计块布局；标注占比、字号与文本空间上限。
3. 编写 Poster Plan，不允许在成图 CSS 里进行临时手动精修。
4. 渲染器预检越界、标签重叠与字体缺失；检测不到的项目必须人工看全图缩略与 100% 细节。
5. 生成 SVG → 截图/渲染 PNG → 目视对照 Lead 检查标题人格、版面节奏与图像关系。
6. **只允许一次局部布局调参返工**；仍不合格时回到布局选择/字体路线，不再十轮手工挪字。

## 硬禁令
- 默认逐字 `font-size` 大小变奏、逐字旋转、跳跃基线。
- 用 `letter-spacing` + 旋转 + scale 冒充原创汉字字形设计。
- 为“设计感”盲目增加不规则字形而未参考 Lead 的具体字形节奏。
- 标题中文拆成一个字一个 HTML span、再给随机 CSS transform。
- H0 图层在实际导出时偷偷切换字体。

## 输入接口
`python layout_engine/scripts/build_poster_svg.py poster_plan.json poster.svg`
当设置 `--png poster.png` 时，若已安装 cairosvg 会尝试同时导出。真正跨工具预览最好再用 Chromium / Inkscape 核验。


## v0.19 最终合成图检测（替代“生成 SVG 后仅目视”的旧出口）
原 1–6 步维持。步骤 5 后必须执行 `readability/audit_and_repair.py`，并保存每个文字块在**最终渲染**中的局部对比、纹理、主体遮挡和缩略可读性结果。它仅对已核验的允许修改空间做最多两轮小范围修复。低对比未修好不得以“布局大致正确”结束；返回布局策略重选。真实人眼/视觉 Agent 检查仍为最后的必要阶段。详见 `readability/README.md`。
