# Cultural Event Poster Design

一个面向文化展览、演出、阅读、工作坊与市集的海报设计 Skill。把活动内容、视觉风格、构图和文字作为一个整体设计，交付可核验的海报与真实图层。

## 设计思路

以活动事实与传播目标为起点，结合主题、受众、气质、场景选择视觉语法。主风格控制媒介、色彩节奏和标题人格，辅助风格只负责局部。构图按信息关系选择，不把摄影、斜向或留白误当成独立母版。

在生图前先规划准确标题的字数、断行、尺度和信息容量，再生成两版主视觉。文字利用画面原有空间、负形和结构融入图像；不靠补大块纯色底板解决可读性。中文与英文分别排版，共享视觉系统。

## 四处交互

1. **资料核对**：确认主题、语言、用途、尺寸及实际活动信息。缺失项集中收集；只有明确授权才能虚构。
2. **风格确认**：推荐主风格与可兼容的辅助处理，说明依据、代价及构图方向。
3. **主视觉 A/B 选择**：展示两张无正式文字的主视觉与标题位置示意；选定后制作正式标题和正文。
4. **用户评价与自我升级**：先交付，再收集评价、定位问题、局部修改和复评。核心规则只有经过跨案例验证与授权才升级。

每处都保存实际回答；明确指定的决定无需重复询问。批量制作不自动省略确认，沉默也不算批准。用户可明确授权代选，范围只适用于对应项目。

## 八种图片风格

| 编号 | 风格 |
|---|---|
| S1 | 色块剪纸与手工拼贴 |
| S2 | 现实照片与平面介入 |
| S3 | 几何构成与现代主义 |
| S4 | 艺术字体与编辑排版 |
| S5 | 版画与套色印刷 |
| S6 | 二维图形与局部立体 |
| S7 | 像素与模块图形 |
| S8 | 留白与材料诗意 |

分类与 best-poster-creator 的八份风格指南对应。每份指南包含风格语法、适用边界、构图与标题规则，以及主视觉 A/B、艺术字、局部修复的详细提示词。风格定义与构图骨架相互独立。

六个构图母版按视觉锚点关系划分：单核聚焦、双锚对话、组列节奏、路径叙事、连续场域、分群网络。另有竖版 V01–V09 与横版 H01–H09 共18种空间排版模式，提供图文比例、标题位置、阅读路径、适用与失败条件；详见 [排版匹配](libraries/layouts/matching.md)。空间模式不替代六个构图骨架，也不固定绑定八种风格。所有比例只是起点，须按实际字数、主体和渠道修订；上下信息留位不等于纯色底板。

## 文件结构

仓库根目录即 Skill 目录；README 仅介绍项目，运行文件保持以下结构：

```text
cultural-poster-flow/
├── SKILL.md
├── core/          # 流程、四处交互、资料分级、匹配与质量规则
├── libraries/     # 八风格、六母版、字体规则、参考索引
├── scripts/       # 状态检查、提示词准备、真实合成与输出验证
├── tests/         # 行为测试、可读性检查、视觉回归协议
└── feedback/      # 评价字段、案例记录与规则升级条件
```

先读 SKILL.md；按阶段读取 core/。风格详情和提示词在 libraries/styles/，构图在 libraries/layouts/，标题在 libraries/typography/。项目文件和反馈保存在项目目录，不写入技能安装目录。

## 使用

将本仓库克隆到运行环境技能目录下的 cultural-poster-flow 文件夹，在对话中请求使用该 Skill 制作海报，并提供活动资料、用途、语言、尺寸和参考素材。助手按照四处交互推进。

Python 辅助脚本依赖位于 scripts/requirements.txt，建议使用隔离环境。图像生成使用当前环境实际可用的生图工具；脚本本身不提供生图服务。

- 没有参考图：根据活动内容、已确认风格和构图进行文生图。
- 有参考图：先看图并确认用途，再把选中的真实文件传给工具；不保证固定参考强度。
- S2：必须使用可靠的实景照片做平面介入，不能生成另一个场景冒充现场。

项目状态使用 scripts/workflow_state.py 保存；scripts/build_style_prompt.py 的 --state 参数检查前置确认。修改活动资料、风格或候选时重开对应决定，后续确认随之失效。脚本不能验证用户原话真实性，也不能阻止绕过脚本的工具调用。

## 交付与验证

输出分为 01_final、02_hero、03_title、04_text、05_source、06_metadata。无字主视觉、透明标题、透明正文使用同一画布和坐标，可以精确重组成品。正文保留真实可编辑文字源；位图艺术字如实标明不可直接改字。

核验文字准确性、局部可读性、内容完整性和图层重组，另做全尺寸与投放缩略图的设计复核。只有扁平成品或检查未完成时明确标为预览。脚本不识字、不判断审美，也不把嵌入位图的 SVG 称为矢量字形。

自动化回归可运行：

```bash
python -m unittest discover -s tests -p 'test*.py'
```

真实视觉回归按 tests/visual_regression.md 执行；未制作的案例必须标明 NOT_RUN。参考图库需按 libraries/styles/visual-benchmarks.md 核验来源、授权和风格，历史素材不自动视为审定正例。
