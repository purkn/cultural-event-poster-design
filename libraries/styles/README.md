# 八种图片风格：唯一现行分类

本版本与用户提供的 **best-poster-creator v1.1.0** 中 `references/styles/` 一一对齐：相同S编号、名称、视觉语法与边界。它们是8套可执行制作风格，不继续把上一版F1–F6并列作为第二套分类。

| ID | 风格及唯一详细指南 | 成立关键 | 最容易混淆的边界 |
|---|---|---|---|
| S1 | [色块剪纸与手工拼贴](01-cut-paper.md) | 不规则纸片边界/缺口/重叠组织主体 | 不是所有拼贴都成立；区别于S5印刷痕迹 |
| S2 | [现实照片与平面介入](02-reality-intervention.md) | 真实照片与二维元素发生具体互动 | 缺可靠实景先补素材；不是照片上散贴图标 |
| S3 | [几何构成与现代主义](03-geometric.md) | 内容关系转成形状/比例/方向的秩序 | 不是随机圆三角，也不等于某一网格版式 |
| S4 | [艺术字体与编辑排版](04-type-editorial.md) | 标题尺度/笔画/断行/负形主导视觉 | 此风格强调字作视觉核心；其他7类也必须设计H0 |
| S5 | [版画与套色印刷](05-printmaking.md) | 单一木刻/丝网/孔版工艺语法、有限色与印痕 | 不是泛黄做旧，也不叠所有工艺滤镜 |
| S6 | [二维图形与局部立体](06-2d-3d.md) | 平面构成为主，少量有主题意义的体积为辅 | 不是全3D渲染或通用塑料充气物 |
| S7 | [像素与模块图形](07-pixel.md) | 统一模块尺度、阶梯轮廓和有限色 | 不是低清照片滤镜，也不强制正文难辨点阵 |
| S8 | [留白与材料诗意](08-material-poetry.md) | 单材料动作、痕迹与负空间形成意义 | 留白来自设计，不是后补文字底栏；不等于浅灰低对比 |

## 怎么查和怎么用

1. 先从活动内容提炼事实→视觉动作→观众看到的结构，明确题材特异性；不按“非遗/展览”套固定风格。
2. 从此表选1主S、0–2辅S，主S控制整体语法，辅S只负责一个明确局部。每个候选写2条适配证据和1条代价；事实/素材不可行先淘汰。A确认后才生成。
3. 只读所用风格的详细文件。每份文件包含原风格指南、内容转译、色彩/标题/留位、A/B探索、负面限制及看图检查，并在末尾统一提供四阶段详细提示词。
4. `prompts` JSON区块是脚本读取的唯一模板源：`hero_a`、`hero_b`、`h0`、`repair`。先替换所有占位变量，再调用实际可用图像工具；脚本本身不生成图、不确认断点。
5. M01–M06只描述构图骨架；媒介、方向、位置、字形、景深等见 `../design_parameters.json`。S风格不是固定母版。

准备提示词示例（必须自己提供核定蓝图JSON，不会自动补活动事实）：

```bash
python scripts/build_style_prompt.py --style S1 --stage hero_a --values project/06_metadata/prompt_values.json --out project/06_metadata/hero_a_prompt.json
```

相对路径以skill根目录执行；准备结果中透明背景意图要根据实际工具支持处理，不能将“保留输入透明”当作后端参数值。

## 参考图和来源的真实状态

八份源指南是文字规则，附件没有八套审定图库。我们保留385张原图库在 `libraries/reference_index/`；各风格的reference_pool仅是历史候选线索，`new_style_membership=NOT_ASSIGNED`。使用前真实看图筛选并记录来源，不把文件名、旧P桶或程序分数当新S归属结论。

源文件及zip的SHA256记录于 `source-manifest.json`，每份本地指南保留源原文后追加本skill适配。附件的其他规则/脚本未执行，也不扩大外部操作授权。旧F/P资源快照仅放 `../legacy/` 供迁移追溯。

视觉参考的筛选、授权和正反例规则见 [visual-benchmarks.md](visual-benchmarks.md)。当前不宣称已具备八风格审定图库。
