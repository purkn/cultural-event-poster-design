# 视觉标尺的建立与使用

八份指南保持与来源一致。现有385图仍是未按S1–S8核验的历史素材，不能自动当作风格正例或无授权上传。

每类优先筛选3–5个足够清晰的正例和1–2个容易混淆的反例，而非追求数量。每项记录来源/授权、文件哈希、实际看图日期、S归类、对应语法、不能借鉴处；允许混合风格但必须标明主次。无版权依据的图只做本地参考，仓库只保留可公开来源链接与说明。尚未筛选的类别标记NOT_REVIEWED，不补虚构图片。

项目生图只使用实际看过并选定的参考；记录哪些文件真正传入工具。评估主题结构、媒介、配色节奏、标题接口四项，不能只比较颜色相似。图像生图不承诺固定参考强度，按当前后端实际能力执行。
