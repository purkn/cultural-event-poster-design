# 如何匹配版式

## 输入
已确认比例/渠道；标题字数和语言；辅助信息行数；主体数量、方向和不可遮挡区；主风格；活动内容结构。先判定横/竖，不擅自改规格。

## 选择逻辑
| 条件 | 首选候选 | 避免 |
|---|---|---|
| 单对象、强识别 | V06/V04；H01/H02 | 多等大块削弱主对象 |
| 长而细的主体 | V01/V02；H03/H07 | 强行裁成中心圆 |
| 动作或路径、制作过程 | V04/V05；H04/H08 | 无意义散点 |
| 多对象、多节目 | V07/V09；H05/H09 | 信息与对象全同权 |
| 长标题或参加信息多 | V03/V02；H02/H08 | 狭窄竖栏和满画面纹理 |
| 艺术字主导S4 | V02/V09；H04/H08 | 图像先占满字场 |
| 真实照片S2 | 顺照片方向选P2/V03、H03/H08 | 为模板裁掉人物动作和现场线索 |
| 留白材料S8 | V06/V04、H01/H02 | 用装饰填尽空白 |

## 决策产物
写出“选择ID，因为主体/文字/阅读需求……；不用另一ID，因为……”。输出区域表：元素、x/y/w/h百分比、前后关系、必须保留细节。`protected_regions` 手工记录，不宣称自动理解所有人物/作品。参考示意不能代替实际渲染测量。

主视觉、标题、事实区应在同一蓝图规划。标题艺术化的融合可以是共轴、同轮廓、沿动作、共享色块或接触关系；不是必须把字藏在图里。信息区留位从实际核定行数估算，不固定“一律留20%”。
选版式后生成A/B前检查字数与安全区；主视觉出来后重新看图验证留位；若不成立返回构图，不靠无限缩字挽救。


## 与现行流程联合使用

先锁定用户尺寸，再按宽高判断portrait/landscape；正方形不能冒充横/竖，允许人工改写候选并说明。S控制视觉语法，M控制锚点关系，V/H控制空间分配：三者各司其职，不重复分类。

V06中心模式可以承载M01单核，V08对称模式可承载M01单核或M02双锚；V07散点可能是M03近同级或M06异质分群。H05双块可能是M02对话，也可能是M04顺序过程。必须依据真实内容判定，不能硬编码为一对一映射。

风格确认前说明可行的空间模式及取舍，不增加第五个用户断点。A确认后、生成主视觉前完成准确标题粗排与区域蓝图。B同时展示无字图与排版示意；主视觉生成后核查区域是否成立，不成立先局部调整或回构图，不靠无限缩字。

`design_plan.json`记录：style、topology、spatial_mode、orientation、canvas、title_skeleton（text/lines/字数/尺度）、information_lines、regions、protected_regions、reading_path、selection_reason、rejected_alternative、capacity_evidence。regions/protected_regions用0–100的x/y/w/h及角色描述；regions另记录z_order与allow_overlap。保护区仅人工看图标注，模式坐标不等于检测结果。

使用scripts/validate_layout_plan.py检查尺寸方向、模式编号及区域边界；它只检查数据几何，不能证明真实字形容量、遮挡或可读性。protected_regions与正文/标题有矩形交叉时返回人工复核提示，不自动认定实际笔画遮挡。

参考附件未直接提供教程原图，因此只吸收已读文档的空间逻辑，不声称已核验原图。原文所谓上下信息区/底区是空间留位，不默认新加实色卡片；当前图字融合规则优先。
