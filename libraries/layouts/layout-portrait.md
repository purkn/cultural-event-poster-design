# 竖版排版模式

来源：用户上传的九格竖版构图教程。提取空间关系，不复制示例文字、配色和装饰。坐标用归一化百分比：x从左到右、y从上到下；以下是起点，边距默认4–7%，不是固定模板。所有区域需根据标题字数、主体细节和小屏阅读修订。

| ID/结构 | 视觉区域与阅读路径 | 标题与辅助信息位置 | 适用与失败条件 |
|---|---|---|---|
| V01 三分构图 | 主体竖长置于x28–72,y10–82；两侧形成窄信息带，读左→主体→右 | 主标题在左带可纵向断行；右带副信息，底部统一日期/场地 | 细长单对象、工艺骨架；长事实不能挤进两条窄带 |
| V02 左右构图 | 图占左约55–65%，字占右30–40%；也可镜像 | 标题右上，副标题/日期右下，同一对齐轴 | 人物/对象方向朝文字；主体反向逃出画面或中文窄列拥挤需换版 |
| V03 上下构图 | 上部25–40%标题与简要信息，下部50–65%主视觉 | 标题上方成组，参加信息放上部底或最下边 | 强单幅图、较多信息；禁止上部像整段说明书 |
| V04 对角构图 | 主体沿左下→右上或反向跨越；两端形成视觉平衡 | 标题在起点/终点一侧，事实落另一个安静角 | 动作、户外、放飞；角度和字倾斜不必一致，事实保持水平 |
| V05 曲线构图 | 一条S/C线索连接2–3个内容节点，中心空隙形成字场 | 主标题处于曲线开口，信息在路径末端外侧 | 过程、游逛、时间叙事；禁止蛇形装饰绕字却无主题关系 |
| V06 中心构图 | 主体中心x25–75,y28–72；边缘空间环绕焦点 | 标题可上方和下方分组但语义连续；事实在底部 | 图腾、单展品、强识别；避免四角小字抢焦点 |
| V07 散点构图 | 3–5个对象分布在不同尺度节点，一个最大焦点统领 | 主标题在最大留白，事实聚成一组，不随各点散开 | 系列作品、多节目；对象同尺寸会失去阅读次序 |
| V08 对称构图 | 中轴与两侧主体呼应，可局部打破对称 | 标题沿中轴或上方，事实底部成组 | 仪式、成对对象、空间展；不要为了对称复制同一人物或作品 |
| V09 复合构图 | 一个主体结构如中心/左右+一个辅助关系如小路径或边界字带 | 标题与事实仍遵守一条主要轴线 | 内容复杂但有主次；两个独立构图争夺主导即失败 |

## 应用规则
先确定一个焦点，再选标题落位，最后画辅助信息矩形留位。标题不必照教程做竖排，纵向断行必须遵守语义，不能拆活动专名。没有要求不要复制“Designer”、箭头和示例分隔块。
手机缩略图先读出主标题/活动类型与主体；日期和场地在全幅可读。主视觉可突破网格一处，辅助信息保持稳定。避让人物脸、文物关键形态及Logo安全区。
