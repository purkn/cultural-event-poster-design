# 横版排版模式

来源：用户上传的横向排版九格教程，图中实际可辨认九个示例，不把标题中的“10种”当作已看到十种。以下按从左到右、从上到下抽象空间结构；不复制教程绿色封面、PS标识或示例文字。坐标百分比，边距起点4–6%。

| ID/结构 | 主视觉区域 | 标题/信息与阅读 | 适用/注意 |
|---|---|---|---|
| H01 偏右单焦点、左下标题 | 大圆/单对象中心约x58,y48，占画幅40–55%宽 | 左上小署名，左下主标题，底边事实 | 大单对象/材料特写；圆只是占位，可换主题结构 |
| H02 右侧单焦点、左栏文字 | 主体x40–90,y12–82 | 左上主题引导，左下主标题；右下少量参加信息 | 较多文案；与L1区别是左栏分级更完整，不只是换标题位置 |
| H03 左窄字栏、右大图窗 | 图窗x23–94,y8–82，主体完整 | 主标题左侧纵向或短行堆叠；底边横排日期场地 | 横向照片；字栏太窄时改为水平标题 |
| H04 中央横带、上下错位字 | 主视觉横跨x5–95,y25–76 | 主标题左上与右下形成对角呼应，事实左下 | 工艺过程/风线；分置标题仍应连续易读，避免拆专名 |
| H05 左右双块错位 | 两视觉块分别x5–40,y15–65与x58–94,y40–90 | 标题右上，事实左下；大小层级决定主次 | 两个内容节点；不是两个同等权重宣传卡 |
| H06 宽胶囊/中央包围 | 中央宽主体x10–90,y16–86 | 标题沿左下/右下边界呼应，上边放少量说明 | 共同空间/集体活动；不强制圆角，边界字不可压进主体细节 |
| H07 左文字边栏、中央大图 | 图窗x20–84,y18–82，横向物件 | 左边主题/主标题，右边短署名；参加信息底边 | 展览作品；边栏不得四面围满小字 |
| H08 上部视觉场、下部信息底 | 主图覆盖上部约60–70%，标题可位于图场下缘 | 下部30–35%放事实，小字集中对齐 | 图像强、信息多；需避免像图片+文章的普通模板 |
| H09 错位矩形与右标题 | 两主块对角错位，次块明显较小 | 主标题右上成组；事实左下；用一个轴贯穿 | 复合内容/系列；不能机械复制灰矩形，要有主题空间关系 |

## 版式检查
横版可让主体与标题共享横向势能，但不把所有信息排一行挤小。长标题先设计语义断行和字距；实际图形边界可有少量侵入，但事实区不得被高频纹理和颜色跳变淹没。左右宽度只是起点，可按文字实际测量调整。
A/B若使用同一版式，母题与图字关系应显著不同；若换版式，仍要保留已确认的方向、比例和主风格。
