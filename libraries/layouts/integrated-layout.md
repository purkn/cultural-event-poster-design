# 图字一体排版与设计复核

参考：[Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)，2026-10-15 阅读。此处借鉴设计方向、主题驱动字体、视觉层级、主动构图及自评原则；不把海报转成网页，也不把前端框架、按钮、卡片、交互要求强加给平面海报。无需另装技能。

## 排版决策

先写简短设计计划：从活动内容与受众推导配色、H0 性格、正文、对齐轴及阅读顺序；标题应是视觉构成的一部分。只设有用的文字层级；信息分组靠位置、大小、间距与对齐表达，不能靠套用页面区块。英文重新分行和调整宽度，保持与中文相同的视觉角色。

文字默认直接加在主视觉之上。优先利用画面原有低细节区域、色块和明暗结构，不强行把图压在中段，也不先预留上下一大块纯底。每次与已选无字主视觉并排复核：主体的尺度、动势、明度和关键边缘是否保留；文字是否与图像的节奏呼应。信息足够多时可分区，但分区应借助原画空间，而非生成独立信息底板。

## 可读性修复顺序

先判断问题发生在哪些实际笔画和背景位置；不要把整个文字框当作实心字块。

1. 在主视觉内部移动、换行、调整宽度与对齐，避开关键主体。
2. 调整字重、字号、字距或文字颜色；H0 可用少量必要的细描边或轻阴影，保持字形清楚。
3. 必要时以图像工具调整文字附近的局部亮度、细节或纹理，保持画面连续；对比无字主视觉与成品，不能让调整变成可见矩形色板。
4. 仍不清楚时重新安排图字关系，或在既有授权内定向修图；不能用大面积纯色页眉、页脚、矩形蒙版、半透明卡片遮住画面以换取 PASS。不能只为安置标题而缩小已选主视觉。

用户明确要求底板，或已批准的设计本来就是版画色块/拼贴纸片时，可以使用对应元素；不得把后补救急底板冒充原生拼贴。不设通用的底板面积百分比当作自动审美标准。

## 双重复核

- 可读性：逐字核对准确性；完整尺寸及实际投放尺寸检查字形、字号、对比与遮挡。图像式 H0 的 `font_px` 应估算保守值，并注明估算，不伪报字库参数。
- 图字构成：标题是否参与画面、阅读顺序是否清楚、主视觉是否被遮盖/缩小/截断、是否出现无关卡片或按钮、两种语言是否保持一致视觉方向。
- 数值报告不评价构图。即使像素报告 PASS，设计复核失败也不能宣称最终版通过。若数值模型不适用艺术字，明确保留 FAIL/ERROR 和原因，不伪造 PASS；修复或交付标注状态的预览，并说明实际限制。

在 `06_metadata/quality_<语言>.json` 的 `design_review` 及观察项 记录简短证据：`text_accuracy`、`h0_visual_role`、`visual_preservation`、`text_on_visual`、`backplate_usage`、`full_size_review`、`thumbnail_review`、`verdict`（PASS/FAIL/INCOMPLETE）。各项写实际观察及相关预览路径，不只填自我评分。成品需要四类硬门禁与设计复核均 PASS；两项美学分另存 aesthetics。
