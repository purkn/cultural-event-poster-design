# S01 — Playful Doodle / 年轻手绘涂鸦 · Style Definition 1.1

## 核心
被设计过的稚拙感 + 艺术字 + 不均质手作痕迹 + 有意尺度反差 + 松弛但受控。

## 运行说明
当前 Style Pack 遵循 v0.13 Core Engine；四个子风格用于路由与参考锚点，不代表每次都要平均混合。
必须先选 primary substyle，再在同一子风格内比较概念。

## 子风格
- S01A_BOLD_ARTWORD
- S01B_NAIVE_CHARACTER
- S01C_SOFT_OBJECT_EDITORIAL
- S01D_ZINE_COLLAGE

Anchor 对应见 `SUBSTYLE_ANCHORS.md`。

## 全局禁止
- 奶油底 + 平均一圈 icon 就算“手绘风”
- 所有线条同粗细 / 同笔刷
- 只靠主题物件数量证明主题
- H0 用自由生图产生伪字
- rough 阶段借口“只是草图”而漂离参考图
- 好插画但没有海报结构
