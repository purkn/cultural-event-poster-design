# Failure Case — 咖啡生活节 v0.6

## 表面上做对了什么
- 奶油底
- 咖啡棕 / 蓝 / 绿点缀
- 有蜡笔 / 涂鸦质感
- 有 H0 艺术字
- 有咖啡杯、壶、豆、可颂、猫、植物
- 信息完整

## 为什么仍然失败
### 1. 没有创意命题
核心逻辑只是：
`咖啡主题 → 把咖啡相关物件画一圈`

这是主题物件清单，不是视觉概念。

### 2. Sticker Sheet 模板感
标题居中，四周均匀分布小图标，所有元素都在“装饰标题”。
缺少：
- 尺度异常
- 单一强隐喻
- 角色动作
- 标题与图像真正融合
- 偏心张力

### 3. H0 仍然可替换
“咖啡生活节 / COFFEE LIFE FEST”虽然是手绘胖字，但换成“面包生活节 / PICNIC FEST”仍然可以原样套用。
所以它是“手写字体风格”，不是“主题专属艺术字”。

### 4. 介质过度统一
杯子、壶、面包、猫、植物都像同一套 AI icon 包。
参考图的好看往往来自不同介质 / 不同线条密度 / 不同尺度的碰撞。

### 5. 信息区 UI 化
底部 `FREE ENTRY` 像网页按钮；DATE / HOURS / VENUE 像标准信息模板，与上方手绘世界断裂。

## v0.7 如何避免
- 先做 4 个完全不同的 Concept；
- 禁止默认 DOODLE_CONSTELLATION；
- H0 做 Interchangeability Test；
- 参考图并排比较；
- 套用 Genericness Penalty；
- 如果 Concept FAIL，不能靠修透明背景 / 坐标 / 字体宣称完成。
