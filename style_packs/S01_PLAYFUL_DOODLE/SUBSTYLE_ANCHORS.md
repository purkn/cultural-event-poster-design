# S01 子风格 Anchor Map

## P01–P10 对应参考图
参考图位于 `references/positive/`。

## S01A_BOLD_ARTWORD — 大艺术字 / 强字图关系
核心 anchors：
- P01：大蓝色艺术字 + 黑白角色 + 明亮局部色
- P03：蓝色手写大标题 + 极简线描物件
- P08：超长蓝色线性标题 + 少量示意图形
- P10：高饱和块面大字 + 极简笑脸符号

Style Fingerprint：
- H0 占明显视觉面积
- 字形本身有不规则节奏
- 图像数量可少
- 亮色集中在标题 / 核心符号
- 不是厚黑复古 tattoo lettering

## S01B_NAIVE_CHARACTER — 稚拙角色 / 童画叙事
核心 anchors：
- P05：猫角色 + 文具 / 调查物件
- P06：儿童画角色 + 彩色涂鸦
- P07：松弛线描 / 水彩小场景
- P09：蓝色鸟形 + 儿童狂想语气

Style Fingerprint：
- 角色造型朴拙
- 表情简单
- 场景简化，不能画成完整绘本
- 角色 / 物件之间有一个明确关系
- 保持海报层级，不靠大量小细节讲故事

## S01C_SOFT_OBJECT_EDITORIAL — 淡彩生活物件 / 轻编辑
核心 anchors：
- P02：半透明淡彩生活物件 + 绿色大标题
- P07：柔和色、轻手绘、留白
- P09：浅底淡彩 + 大面积呼吸空间

Style Fingerprint：
- 浅底
- 物件色彩低对比 / 半透明
- 线条轻
- H0 可以较平，但仍需有艺术字性格
- 不允许漂移成复古水彩插画 / 静物画

## S01D_ZINE_COLLAGE — 独立出版 / Zine 拼贴
核心 anchors：
- P04：高饱和绿色大场 + 手写 / 标签 / 线条
- P05：文具节的编辑感 + 手绘碎片
- P06：童画、线稿、文字多层混合

Style Fingerprint：
- 允许叠压、胶带、纸片、印章感
- 但仍保持明亮、年轻
- 拼贴不是泛复古怀旧
- 不默认粉黑朋克
- 主题专属性必须来自内容结构，不只是一枚 stamp
