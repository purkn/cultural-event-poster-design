# Reference Delta Gate v0.13

## 核心
Reference Delta 分为三张表：Structure / Surface / Typography。

## A. Structure Delta
至少比较：
- H0 area ratio
- hero area ratio
- information area ratio
- dominant visual center
- main axis
- type-image relationship
- negative-space location
- density heatmap

## B. Surface Delta
至少比较：
- medium_class
- dimensionality
- background_value_regime
- chromatic role count
- dominant/accent ratios
- mark_frequency
- lighting_model
- surface_finish

## C. Typography Delta
至少比较：
- skeleton class
- stroke contrast
- weight
- width/proportion
- arrangement
- fill behavior
- effect class
- H0 color role

## GREEN
在 Blueprint 容差内。

## AMBER
局部偏差，但不改变视觉世界。

## RED — Hard
任一成立即 RED：
- high_key ↔ low_key 反转
- flat/print ↔ volumetric/3D/generative-glow
- H0 weight 跨 2 级以上
- flat solid H0 ↔ multi-color gradient/glow without Lead evidence
- type-image relationship 完全改变
- 4 个以上结构变量偏离
- Surface 表出现 2 个以上 RED
- Typography 表出现 2 个以上 RED

RED 不得用“更符合主题”自动解释。

## 禁止话术
