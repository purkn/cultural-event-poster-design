# 海报分类与参考逻辑

以下分类从用户提供的七组海报参考提炼，是本技能的工作分类，不声称来自未读取的分享对话，也不是互斥的艺术史分类。

先记录活动用途：展览 / 艺术节与阅读节 / 社区市集 / 非遗与传统文化 / 其他。再选视觉类别，最后确定版式策略。活动用途决定信息，视觉类别决定语言，版式决定阅读路径。

|编号与类别|视觉语言|适合的传播气质|参考组|常见偏差|
|---|---|---|---|---|
|01 国风叙事与传统插画|人物或工艺场景、纸本纹理、赭红墨色、书写性标题|工艺故事、人文历史、非遗体验|第2组制茶/豆腐；第7组传统文化|堆砌印章祥云，混淆历史服饰，把生成图当真实文物|
|02 现代东方与意象构成|提炼器物、山水和窗格轮廓，柔和色块、留白、现代网格|当代文化展、地域文化、园林与生活美学|第6组苏韵流芳、寻美岭南、茶食集|只剩渐变与装饰，看不出活动主题|
|03 趣味插画与角色场景|扁平人物、拟人道具、鲜明撞色、夸张动作|亲子、艺术节、阅读、市集、节庆|第1组阅读节/艺术在场；第5组|角色抢过标题，所有活动都用同一套卡通人物|
|04 轻盈手绘与自然诗性|疏朗线描、植物、拓印、低饱和浅色、呼吸感|独立艺术、书展、自然与社区活动|第3组；第4组局部|颜色浅到不可读，手写体小字过多|
|05 几何符号与字体构成|放大标题、几何拼块、图标、模块与清晰网格|当代设计、公共艺术、城市文化活动|第1组街头流动舞台；第4组公园节局部|形式炫技而无主题联系，字形变形到无法识别|
|06 复古印刷与实验拼贴|剪纸轮廓、颗粒网点、套色错位、纸感和非规则排版|青年文化、音乐、独立市集、实验艺术|第4组不拘小集/开新；第5组部分市集|过度做旧，信息碎片化，误把参考水印当装饰|

参考组编号对应本次用户附件顺序。图片只作为设计研究材料，不附带使用其Logo或作品的许可；未来没有这些图片时，仅依据本表也能完成分类，不依赖原电脑下载路径。

## 生成四版的办法

在同一选定类别内，以活动的具体内容提出四个母题，不机械套用四种颜色。以下仅为发散工具，可按主题改写：

- A：单一主题符号占据主要画面，标题与之建立清楚关系。
- B：人物/物件形成叙事场景，信息跟随场景节奏。
- C：主题形态与标题融合，文字自身成为主要图形。
- D：系列元素以模块、节奏或路径组织，呈现活动的多样内容。

例如“城市阅读节”可以分别探索“书页化作城市”“人物穿行书中”“标题成为书架”“阅读轨迹地图”；不能给无关活动默认套用书本母题。04类仍需保持疏朗，01类仍应尊重内容语境，结构区别不应破坏已选风格。

每版记录：名称、核心概念、主图、标题位置、信息区、主辅色与识别优势。判断差异时先忽略颜色，若仍像同一张图，应重做其中的概念或构图。
