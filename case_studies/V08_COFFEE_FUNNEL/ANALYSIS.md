# v0.8 咖啡生活节概念漏斗：系统层诊断

## 值得保留
- Concept-first 的方向正确；
- Anti-cliche filter 有价值；
- Concept Card 中强制描述 H0、负空间、海报化与风险是有效约束；
- 先文字再生图能降低沉没成本。

## 需要修正
### 1. Style Route 出现在 Theme Insight 之前
多风格系统中会造成先入为主。v0.9 改为先 Design Context / Asset Audit / Theme Insight，再选 Style Candidates。

### 2. “使用全部 12 种操作器”不是质量指标
它容易让系统围绕工具库发散，而不是围绕设计问题发散。v0.9 删除 operator coverage KPI。

### 3. 专属性表述有过度辩护
像“蒸汽只属咖啡”不是可靠事实。v0.9 用 Structural Binding + Swap Test 替代口头唯一性。

### 4. 没有记录 Asset Usage
未来每张 Concept Card 必须明确：用了哪些用户素材、怎么改、若不用高价值素材为什么不用。

### 5. 信息承载检查太晚
未来 Concept Card 必须声明 factual info zone 与英文扩展策略。

## v0.9 保留的最佳部分
保留“文字概念漏斗”，但升级为**跨 Style Candidate 的 Route Pool**，不是先固定一个 Style 再把所有概念塞进去。
