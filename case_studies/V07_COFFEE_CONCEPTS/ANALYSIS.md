# v0.7 咖啡生活节四概念案例分析

## A — Title as Hero
判定：**概念有潜力 / 风格与字形执行不通过**。
- 优点：H0 真正成为主视觉。
- 问题：自由生成中文造成字形不可靠；黑灰粗重描边偏 tattoo / retro；和 S01A anchor 的明亮、松动、轻快有距离。
- v0.8 修法：先 exact glyph skeleton，再做主题化材质与变形；绑定 P01/P03/P08/P10。

## B — Single Metaphor
判定：**概念尚可 / Style Route 错位**。
- “慢”进入咖啡液面的隐喻清晰。
- 但画面漂向复古淡彩静物 / 水彩，不够年轻活动海报。
- 说明 v0.7 把“概念”和“子风格”同时改变，导致比较无效。

## C — Character Scene
判定：**插画成立 / 海报不成立**。
- 巨型咖啡壶的尺度反差有趣。
- 但缩略后主要是复杂故事场景；小人物与环境细节过多；H0 无明确结构位置。
- v0.8 Posterization Gate 应淘汰或重构为更图形化的 2–3 个质量块。

## D — Zine Collage
判定：**版面张力较强 / 主题专属性与 anchor fit 不足**。
- 叠压、纸张、stamp 有视觉能量。
- 但粉黑朋克感偏离 S01D anchor；替换 coffee stamp 后可轻易变成唱片节 / 文具节。
- v0.8 要求主题专属性与 anchor-relative 两道门。

## v0.8 从该案例吸取的最重要规则
1. 概念比较时固定风格。
2. 风格比较时固定概念。
3. rough 也必须保留 style-critical variables。
4. 不是所有好插画都是好海报。
5. H0 艺术字先保证字形，再谈风格化。
